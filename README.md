# 🏦 Bank Customer Churn Analysis Dashboard

## 📌 Project Overview
This project analyzes bank customer churn using Power BI. The dashboard helps identify customer behavior, churn trends, and key business insights through interactive visualizations.

## 🛠 Tools Used
- Power BI
- Power Query
- DAX
- CSV Dataset

## 📊 Dashboard Features
- Total Customers
- Churned Customers
- Active Customers
- Churn Rate
- Average Balance
- Customers by Geography
- Customers by Gender
- Churn by Geography
- Churn by Gender
- Credit Score Distribution
- Age Group Analysis
- Tenure Group Analysis
- Product Usage Analysis
- Active Member Analysis
- Credit Card Holder Analysis

## 📈 Key Insights
- Customer churn varies across different countries.
- Middle-aged customers show higher churn.
- Active members are less likely to churn.
- Customers with different credit scores exhibit different churn behavior.
- Product usage and tenure influence customer retention.
